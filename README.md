# 基于 Ollama 的递归经验学习系统

本项目使用原始 `gpt-oss:20b`。学习对象是跨请求保存的经验规则，**不更新模型权重**。如果课程要求参数微调，本项目不能代替该要求。

## 提交版本与实测结论

本项目为课程作业二方案 b。已保留三轮学习日志和独立测试输出。验证集完全正确率从 93.3% 升至 96.7%；独立测试集基础提示与经验提示均为 100%，未证明测试泛化收益。设计细节见 [设计与验证说明](docs/design.md)，实验数值见 [实验报告](results/report.md)。

第一次使用先安装 [Ollama](https://ollama.com/)，并运行：

```powershell
ollama pull gpt-oss:20b
ollama run gpt-oss:20b
```

确认模型能回答后退出该交互，在项目目录运行下面的 Python 命令。仓库不含模型权重；下载和推理所需磁盘、内存、显存由本地环境提供。提交日志使用原始模型，不需要自定义 Modelfile。

## 环境与运行

需要 Python 3.10+、已启动的 Ollama 和已下载的 `gpt-oss:20b`。仅使用 Python 标准库，无须安装 pip 依赖。

在本目录打开 PowerShell：

```powershell
python rsl.py demo
python rsl.py learn --rounds 3
python rsl.py evaluate
```

快速学习演示（只取9条学习样本、1轮，仍使用完整验证集）：

```powershell
python rsl.py learn --rounds 1 --limit 9
```

每次 learn 从空经验库开始，覆盖上次 memory.json 和同名学习日志。需要保留实验时先复制 results 和 memory.json。

自定义文本：

```powershell
python rsl.py chat --text "李四去南京参加培训，日期和预算尚未确定。"
```

交互抽取：`python rsl.py chat`，输入 `/bye` 退出；也可双击 `运行聊天.cmd`。这是信息抽取入口，每条输入独立处理，并非通用多轮聊天。

重新生成数据：`python rsl.py init`。验证检查器：`python -m unittest test_rsl -v`。

## 任务规范

提取一个最终有效的活动。五个字段必须存在：person 为姓名，date 为明确日期 YYYY-MM-DD，location 为活动发生地，event 为原文活动动词和宾语，budget 为元单位数值；缺失项为 null。金额不能为字符串或布尔值。范围外文本（多个未指定目标活动、复杂相对日期等）不在第一版数据集内。

## 学习闭环

1. 读取已有经验，模型首次抽取。
2. 学习集标准答案提供字段错误反馈，最多修正两次。
3. 修正成功才让模型提炼一般规则，不直接保存案例答案。
4. 在固定验证集上比较新增规则前后结果。完全正确率严格提高，且原来正确的样本没有退步，才接受规则。
5. 新经验影响后续样本与下一轮，最多保存15条。history.json 记录失败、修正、候选与接受理由；每轮有经验快照。

模型调用使用 JSON 输出模式、4096上下文、low推理强度、temperature=0、seed=42。这些是请求参数，不创建 Ollama 自定义模型。种子与低温不能保证跨硬件或版本完全一致。

## 数据与评测

data 中90条学习、30条验证、30条测试样本由 make_data.py 确定性生成。三个集合使用不同表达模板，包含出发地干扰、地点更正、缺失字段与无关预算。标准答案由模板对应的明确字段生成。

数据是教学用合成数据，模板数量少、实体有重叠，独立性和泛化覆盖有限。提交正式报告前应人工复核，并补充真实表述与更多独立模板。不要宣称这是通用抽取能力评测。

evaluate 冻结 memory.json，分别运行基础提示与基础提示加经验。测试答案只用于计分，不进入模型提示或经验库。每条样本仅调用一次，比较首次回答表现。report.md 记录完全正确率、字段准确率、JSON对象率和平均耗时，evaluation.json 保留全部输出。

如果模型基线已经满分或没有候选经验通过验证，经验库可能为空。此时系统闭环存在，但本次实验没有证明学习收益；报告必须如实说明。增加任务难度时先确定标准，不能为制造提升而刻意削弱基线或向测试提示泄漏答案。

## 运行问题

连接失败：打开 Ollama。模型不存在：`ollama pull gpt-oss:20b`。长任务可 Ctrl+C 终止，已完成学习记录逐样本写盘。请求超时为600秒；接口错误会停止，避免把服务故障当作模型答错。评测应在固定服务配置下运行，重复使用验证集存在过拟合风险。
